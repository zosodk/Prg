# Programmering - Ugentlige Opgaver

Dette repository indeholder mine praktiske opgaver og kodeløsninger i faget **Programmering**. Alle opgaver er skrevet i Python.

## 📁 Filstruktur og Navngivning

For at gøre det nemt at finde rundt i opgaverne, er alle filer navngivet ud fra et fast system baseret på undervisningsugen og opgavenummeret:

> `uge<ugenr>opg<opgavenr>.py`

**Eksempler:**
* `uge36opg1.py` (Løsning til opgave 1 i uge 36)
* `uge36opg2.py` (Løsning til opgave 2 i uge 36)
* `uge37opg1.py` (Løsning til opgave 1 i uge 37)
